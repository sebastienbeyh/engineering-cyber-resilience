*Engineering Cyber Resilience* presents a systems-oriented approach to cyber resilience across modern digital and critical infrastructure.

The work examines the interaction between:

- Networks
- Artificial intelligence
- Cybersecurity

- Critical infrastructure
- Quantum-safe security
